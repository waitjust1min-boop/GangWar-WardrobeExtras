GANG WAR - WARDROBE EXTRAS  (for Gang War version 1.0.12)
==========================================================

26 more hats and 900+ clothes, hairstyles and faces of the game's other men for Niko's wardrobe, each with fit sliders.
You need Gang War itself (the main download) installed first.

INSTALL
  1. Drag everything from this zip into your GTA IV folder (the folder with GTAIV.exe in it).
  2. Close the game, then double-click   GangWar - Install wardrobe extras.bat   (now next to GTAIV.exe).
  3. Start the game: GangWar menu (P, or LB + SELECT) > WARDROBE tab.

  - If Windows warns about the file: click "More info" > "Run anyway".
  - If it says "access denied": right-click the file > "Run as administrator".

WHAT IT DOES
  The looks are built from YOUR OWN game files in about 2 minutes - nothing of Rockstar's is in this download. It changes
  two game files (pc\models\cdimages\pedprops.img for the hats, playerped.rpf for the clothes, hair and faces) and keeps
  the originals in the "GangWar_backups" folder first. Everything in this zip is a plain-text script you can open and read:
  the two .bat files only start the PowerShell installers in scripts\GangWar_tools\ (hats_installer, clothes_installer),
  whose C# helper files are compiled on your PC when they run.

UNINSTALL
  Close the game and double-click   GangWar - Uninstall wardrobe extras.bat   - the original files come back.

NOTES
  - The fit sliders (WARDROBE tab) take effect when you quit GTA IV: the installer rebuilds the looks as the game closes.
  - A new face hides Niko's own eyes and teeth (it has its own); his hair 3 (shaved) suits most faces.
  - The faces keep a calm look: they don't move with Niko's expressions.
  - Tested on GTA IV: The Complete Edition (1.2.0.59). If another mod changed pedprops.img, the installer asks first.
